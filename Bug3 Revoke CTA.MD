Revoke CTA is enabled after party is seated.

Launch and login to TM Ship.

Navigate to Host module-->Click on the Search CTA.

Search for any Sailor and create reservation for the selected venue.

Select the created reservation from the left panel.

Select any table and Click on Seat party.

Click on the edit icon .

Expected Result: Revoke CTA should be disabled when the party seated.
Actual Result:
